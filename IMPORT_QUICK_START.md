# 🚀 Quick Start: Employee Bulk Import

## ⚡ 4 Easy Steps to Import Employees

###  **STEP 1: Download the Template**
- Click the **"Import"** button on the employee page
- Click **"Download CSV Template"** in the modal
- A file named `employee_import_template.csv` will download

### 📝 **STEP 2: Fill in Your Employee Data**
Open the CSV file in Excel and fill in employee information:

**Required Fields (MUST fill):**
- ✅ First Name
- ✅ Last Name  
- ✅ Email (must be unique!)

**Optional Fields (nice to have):**
- Middle Name
- Gender (male/female)
- Phone Number (+251911234567)
- Position (Senior Nurse, Doctor, etc.)
- Department
- Employment Type (full-time, part-time, contract)
- Salary (numbers only)
- Join Date (format: 2024-01-15)
- Status (active, on-leave, inactive)
- Working Location  
- Date of Birth (format: 1990-05-20)
- Address

**💡 TIP:** The template comes with 3 sample rows - delete these and add your real data!

### 💾 **STEP 3: Save as CSV**
1. In Excel, click **File → Save As**
2. Choose format: **CSV (Comma delimited) (*.csv)**
3. Click Save
4. If Excel asksto confirm, click **Yes**

### 📤 **STEP 4: Upload & Import**
1. Go back to the Import modal
2. **Drag & drop** your CSV file OR click to browse
3. Review the file name and size
4. Click **"Upload & Import"**
5. Wait a few seconds for processing ⏱️
6. ✅ Done! The page refreshes automatically

## 🎯 Quick Tips

✨ **Start Small:** Import 5-10 employees first to test  
✨ **Check Emails:** Make sure each email is unique  
✨ **Use Dates Correctly:** Format as YYYY-MM-DD (e.g., 2024-01-15)  
✨ **Keep a Backup:** Save your original Excel file  
✨ **Read Error Messages:** They tell you exactly what went wrong

## ❓ Common Questions

**Q: Can I use Excel files directly?**  
A: No, you must save as CSV first. Excel files coming in future updates!

**Q: What if some rows fail?**  
A: The successful rows will still be imported. Fix the errors and re-import those rows.

**Q: Can I update existing employees?**  
A: Not yet - this feature only adds new employees. Updates coming soon!

**Q: Is there a limit on file size?**  
A: Keep files under 100 employees for best performance.

**Q: What happens to duplicate emails?**  
A: The import will skip that row and show an error. Each email must be unique!
